What’s inside

Useful tools. More atmosphere.

Designed to make building more convenient and give the Overworld a little extra life.

🪓

Builder’s Axe

Select two points and build walls, floors, roofs, fills, outlines, or clear selected areas.

🔎

Live Build Preview

See the selected area and block count before the building operation starts.

↶

Undo

Undo up to four recent building operations.

🌌

Starry Night Sky

Colorful stars, a Milky Way effect, shooting stars, and moon phases.

🍃

Windy Leaves

Animated leaf textures and drifting leaf particles; cherry trees can release pink petals.

✨

Extra UI & Effects

A colorful experience bar, torch-light simulation, player list, and an off-hand swap command.

Quick reference

Command list

Use these commands in a world where the add-on is enabled.

/axeGet the Builder’s Axe.
/menuOpen the building tool menu.
/undoUndo a recent building operation (up to four).
/mode wall|floor|roof|fill|outline|clearSelect a building mode.
/material oak_planksChoose a material; use /materials to view the list.
/height 5Set wall height from 1 to 40.
/sky on|off|meteorControl night-sky effects or trigger a shooting star.
/playersShow the online player list.
/offhandSwap the selected item with the off-hand slot.
/buildinfo · /cancel · /bbhelpView settings, cancel point A, or open help.

CompatibilityThe package declares Minecraft Bedrock engine version 1.21.130 as its minimum and uses @minecraft/server 2.4.0. Actual compatibility should be tested in your game version.
How to installOpen the .mcaddon file on a supported device to import both packs, then activate the Behavior Pack and Resource Pack in your world settings.
Testing note: This project has not been confirmed through a full in-game test. Some effects or commands may need fixes depending on the Minecraft version and device. Leaf motion is a texture animation, not physical bending of leaf blocks.
